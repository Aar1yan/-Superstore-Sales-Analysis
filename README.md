# Retail Sales Data Analysis

## Overview
A beginner-level data analysis project using the Superstore Sales Dataset.
The project focuses on practicing Pandas, NumPy, Matplotlib, and Seaborn through real-world sales analysis.

## Objectives
- Analyze sales performance
- Analyze customer and product performance
- Analyze regional performance
- Analyze profitability
- Identify patterns and outliers in the data

## Analysis Covered
- Category-wise sales
- Monthly sales
- Top customers
- Top-selling and rarely sold products
- High-sales, low-quantity products
- Regional performance
- Average Order Value by region
- Product profitability
- Category profit margins
- Loss-making products

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook

## Dataset
Superstore Sales Dataset.

## Project Type
Practice / Mini Project — Exploratory Data Analysis (EDA)

## Note
This project was created primarily to practice data manipulation,
aggregation, analysis, and visualization using Python.
